## 2. 需要真实样本的验证

样本可以放回本地，建议按以下目录组织（不必提交到 Git）：

```text
<trip-trace-samples>/
  border/          # 漠河、长白山等边境照片
  overseas/        # 韩国/日本/欧洲等境外照片
  iphone/          # HEIC + MOV（带 GPS/creation_time）
  collisions/      # DCIM/100APPLE、DCIM/101APPLE 等同名文件
```

需要重点确认：

1. **边境**：
   - 选“国内行程”，漠河/长白山坐标不能出现俄罗斯/朝鲜地名；
   - 边境 50km 缓冲内的坐标能走高德；
   - 异常数量符合预期。
2. **境外**：
   - 选“境外/混合”，城市名正确；
   - Nominatim 有城市/区；
   - Overpass 可用时景点名合理；不可用时为空但不报错；
   - 高德不处理境外坐标。
3. **HEIC/视频**：
   - HEIC 能读拍摄时间/GPS；
   - 视频时间不是文件 mtime；
   - 无时间的文件进入待审核。
4. **同名冲突**：
   - 不同 DCIM 子目录的同名文件都保留；
   - 输出目录结构与源相对路径一致。

## 4. 已知限制（验收时不要误判为 bug）

- `planId` 目前不跨应用重启持久化，重启后需要重新生成方案；
- 没有 `DELETE` 方案、按时间拆分、执行幂等/只重试失败项；
- 大行程合并时源容器不迁移；
- 公共 Overpass 可能 502，境外景点可能为空；
- 图片备注用 Pillow 重编码，可能有质量损失；
- M7 清理删除了旧接口，旧会话/旧前端缓存可能提示重新生成方案。
